Resize and crop multiple images at once

Drop in a folder of photos, set one output size, and every image comes out at exactly those pixel dimensions. Each image gets its own draggable crop window, so you decide what stays in frame instead of letting an automatic centre-crop cut off heads and edges. High-quality downscaling is done with Lanczos resampling, so shrunk images stay sharp rather than muddy.

Typical uses

  • Preparing a machine-learning dataset where every sample must be the same size (224×224, 512×512…).
  • Batch-resizing product photos, avatars or thumbnails for a shop or website.
  • Forcing a mixed set of photos into one aspect ratio for a grid or slideshow.
  • Converting a batch to WebP to cut page weight.

Everything runs in your browser with the Canvas API. Your images are never uploaded to a server — there is no upload limit, no queue and no watermark.
