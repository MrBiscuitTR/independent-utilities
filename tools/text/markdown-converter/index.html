Markdown to HTML, and back again

Type or paste on the left and watch the result on the right. Switch direction with the tabs: Markdown → HTML renders your Markdown and gives you the generated HTML source, while HTML → Markdown takes pasted markup and turns it back into clean Markdown — useful for moving a page into a README, a wiki or a static-site post.

Supported

  • GitHub-flavoured Markdown: tables, task lists, strikethrough, fenced code blocks with syntax highlighting.
  • Headings, lists, blockquotes, links, images, inline code and horizontal rules in both directions.
  • Drag several .md or .html files in at once — each opens in its own tab.
  • Drag the divider to resize the panes, or turn the split preview off.

The parser (marked) and the highlighter (highlight.js) are bundled with this page rather than loaded from a CDN, so the converter works with no internet connection and your document is never sent to a server.
