Fancy text you can paste anywhere

Type once and get every style at the same time — bold, italic, cursive script, gothic fraktur, double-struck, monospace, ⓑⓠⓑⓑⓛⓔ letters, ᴀᴍᴀʟʟ ᴄᴀᴘᴟ, ＶＡＰＯＲＷＡＶＥ full-width, uʍop-ǝpısdn, s͡t͡r͡i͡k͡e͡t͡h͡r͡o͡u͡g͡h͡, underline, superscript, subscript and glitch text — then hit Copy on the one you want.

These are not fonts in the usual sense, which is exactly why they work: each style maps your letters onto real Unicode characters that already exist (mathematical alphanumerics, enclosed alphanumerics, small-capital letters, combining marks). Because it is plain Unicode text, it survives copy-and-paste into an Instagram bio, a Discord message, a TikTok caption, a Twitter/X post, a Steam name or a Word document — no image, no font file to install.

Worth knowing

  • Some apps and older devices show a box (□) for styles they lack a glyph for — check before publishing.
  • Screen readers often cannot read styled Unicode aloud, so avoid it for text that must stay accessible.
  • Everything runs in your browser; what you type is never sent anywhere.
