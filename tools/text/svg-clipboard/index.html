Inline SVG icons, copied straight into your markup

Pick an icon, set the size, stroke width and colour, and click it — the full <svg>…</svg> element lands on your clipboard, ready to paste into HTML, JSX, Vue or a Figma frame. No icon font, no npm package, no build step and no extra network request on your own site.

Why inline SVG

  • It inherits currentColor, so an icon can follow your text colour and theme.
  • It scales cleanly at any size and on any display density.
  • It adds no HTTP request, unlike an <img> or an icon font.
  • You can animate or style individual paths with plain CSS.

The set covers what interface work actually needs day to day: arrows and chevrons, hamburger and kebab menus, close and plus buttons, checkboxes and toggles, search, settings, trash, copy, download, eye and lock, play/pause and volume, user, mail, share, and common file, calendar and cart shapes. All icons are drawn on a 24×24 grid, so they line up with each other.
